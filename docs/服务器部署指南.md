## 部署步骤

### 第一步：准备部署文件

确保以下文件已上传到服务器：

```
KyInfo/
├── docker-compose.yml           # Docker 编排配置
├── KyInfo.Api/
│   └── Dockerfile              # API 服务 Dockerfile
├── KyInfo.Blazor/
│   └── Dockerfile              # Blazor 前端 Dockerfile
└── 源代码文件...
```

### 第二步：连接服务器

使用 SSH 连接到服务器：

```bash
ssh root@47.93.197.37
# 输入服务器密码
```

### 第三步：上传项目文件

使用 SFTP 或 SCP 将项目文件上传到服务器：

```bash
# 使用 scp 上传（本地执行）
scp -r /path/to/KyInfo root@47.93.197.37:/opt/

# 或者使用 sftp
sftp root@47.93.197.37
put -r /path/to/KyInfo /opt/
```

### 第四步：进入项目目录

```bash
cd /opt/KyInfo
```

### 第五步：修改配置（重要）

编辑 `docker-compose.yml` 修改关键配置：

```bash
vim docker-compose.yml
```

需要修改的配置项：

```yaml
# 1. 修改数据库密码（重要！）
services:
  sqlserver:
    environment:
      - SA_PASSWORD=您的数据库密码

# 2. 修改 JWT 密钥（重要！）
  api:
    environment:
      - JwtSettings__Secret=您的256位密钥

# 3. 如需使用域名，修改 Nginx 配置
```

### 第六步：启动服务

```bash
# 后台启动所有服务
docker-compose up -d

# 查看启动日志
docker-compose logs -f

# 查看运行状态
docker-compose ps
```

### 第七步：验证部署

服务启动后，验证各服务是否正常运行：

```bash
# 查看容器状态
docker-compose ps

# 检查 API 服务
curl http://localhost:5000/health

# 检查 Blazor 前端
curl http://localhost:5001/
```

## 常用命令

### 启动/停止服务

```bash
# 启动所有服务
docker-compose up -d

# 停止所有服务
docker-compose down

# 重启服务
docker-compose restart

# 查看日志
docker-compose logs -f
docker-compose logs -f api
```

### 查看容器状态

```bash
# 查看所有容器
docker ps

# 查看特定容器日志
docker logs kyinfo-api
docker logs kyinfo-blazor
```

### 进入容器

```bash
# 进入 API 容器
docker exec -it kyinfo-api /bin/bash

# 进入数据库容器
docker exec -it kyinfo-sqlserver /opt/mssql-tools/bin/sqlcmd -S localhost -U sa -P 您的密码
```

## 数据持久化

数据库数据存储在 Docker 卷中：

```bash
# 查看数据卷
docker volume ls

# 备份数据库
docker exec kyinfo-sqlserver /opt/mssql-tools/bin/sqlcmd -S localhost -U sa -P 您的密码 -Q "BACKUP DATABASE KyInfoDb TO DISK='/var/opt/mssql/backup/KyInfoDb.bak'"
```

## 故障排除

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 数据库连接失败 | 数据库未启动或密码错误 | 检查 SA_PASSWORD 配置，确认数据库容器状态 |
| API 服务启动失败 | 端口被占用 | 修改 docker-compose.yml 中的端口映射 |
| 前端无法访问 API | 网络配置问题 | 检查容器网络连接，确认 api 服务已启动 |
| 权限问题 | 目录权限不足 | 确保项目目录权限正确 |

### 日志排查

```bash
# 查看所有服务日志
docker-compose logs

# 查看特定服务日志
docker-compose logs api
docker-compose logs blazor
docker-compose logs sqlserver
```

### 端口检查

```bash
# 检查端口是否被占用
netstat -tlnp | grep 5000
netstat -tlnp | grep 5001
```

## 安全建议

1. **修改默认密码**：务必修改 `docker-compose.yml` 中的默认密码
2. **配置防火墙**：开放必要端口，关闭不必要的端口
3. **使用 HTTPS**：生产环境配置 SSL 证书
4. **定期备份**：定期备份数据库数据
5. **更新镜像**：定期更新 Docker 镜像版本
